## App name

PdmApp

## Short description

Monitor your Proxmox Datacenter Manager fleet from Android

## Full description

Bring your Proxmox Datacenter Manager fleet to your Android phone, foldable, or tablet.

PdmApp gives you a native Android view of your remotes, virtual machines, containers, nodes, tasks, and resource usage. Move from a fleet overview to the details you need, with compact and two-pane layouts and a dark interface designed for everyday monitoring.

SEE YOUR FLEET
Review remote health, guest status, CPU and memory leaders, storage, and recent activity. Open supported resource graphs to investigate changes over time.

FOLLOW TASKS
Inspect running and recent tasks, read task logs, and check the outcome of supported operations.

MANAGE SUPPORTED GUEST WORKFLOWS
Start, shut down, or stop guests. Inspect hardware and use supported snapshot and migration workflows. Available controls depend on your account permissions and server capabilities.

INSPECT NODES
Review node resource usage, storage, network interfaces, and pending package updates. Interactive terminals are available where the server, password session, and account permissions support them.

CONNECT WITH CERTIFICATE VERIFICATION
Use password or API-token authentication and supported TOTP challenges. HTTPS certificate verification and pinning help you verify the server you are connecting to. Saved credentials are encrypted on the device.

VIEW CACHED DATA OFFLINE
Enable the optional encrypted cache to revisit previously loaded information when the server is unreachable. Offline views show cached data, and server-changing actions are disabled until a live connection is available.

EXPLORE THE DEMO
Try a synthetic fleet through the built-in demo without entering real server credentials.

PdmApp connects to a Proxmox Datacenter Manager server that you provide. Features vary with the PDM version, connected remotes, and account permissions. OpenID and WebAuthn sign-in are not currently supported in the app.
